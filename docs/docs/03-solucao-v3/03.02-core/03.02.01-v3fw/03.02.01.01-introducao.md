# 📱 Introdução

O **V3FW** é o software embarcado nos dispositivos V3, responsável por coletar, processar e enviar os dados captados pelos sensores para a nuvem.

O **V3FW** foi projetado para operar em diferentes condições, com foco em eficiência e confiabilidade. Sua arquitetura modular permite adaptabilidade a diversos tipos de hardware, mantendo a consistência das funcionalidades e a qualidade do processamento de dados.

## 📚 O que você encontrará nesta seção

Esta seção apresenta as principais funcionalidades e componentes do **V3FW**, detalhando como ele coleta e processa os dados dos sensores. Os principais tópicos abordados são:

- [Telemetria](./03.02.01.02-telemetria.md): Coleta e processamento de dados dos sensores
- [MDVR](./03.02.01.03-mdvr.md): Sistema de gravação e recuperação de mídia
- [Comportamento do Condutor](./03.02.01.04-comportamento-condutor.md): Análise de padrões de condução
- [DMS](./03.02.01.05-dms.md): Sistema de monitoramento facial do condutor
- [Visão Computacional](./03.02.01.06-visao-computacional.md): Processamento e análise de imagens
- [Portabilidade](./03.02.01.07-portabilidade.md): Adaptabilidade a diferentes hardwares
