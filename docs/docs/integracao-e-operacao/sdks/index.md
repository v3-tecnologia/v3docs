# Visão Geral

Esta seção reúne os SDKs oficiais da V3 para acelerar integrações e reduzir complexidade de implementação.

## Objetivo

Os SDKs fornecem uma camada de abstração sobre APIs e fluxos de autenticação para facilitar:

- Conexão com serviços da V3
- Tratamento consistente de erros e retries
- Boas práticas de integração por linguagem

## Conteúdo desta seção

Os SDKs disponíveis atualmente são:

- [SDK Java](./java.md)
- [SDK Kotlin](./kotlin.md)
- [SDK .NET](./dotnet.md)
- [SDK Go](./go.md)

Além disso, aqui você encontrará, em breve:

- Guias de instalação por linguagem
- Exemplos de uso para cenários comuns
- Referência de métodos e componentes
- Recomendação de versionamento e atualização
