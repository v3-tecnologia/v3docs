# 🛠️ Ferramenta de Configuração

A V3 possui uma ferramenta customizável que facilita significativamente o processo de instalação de dispositivos. Esta ferramenta, chamada `V3QATools`, é essencial para garantir uma configuração precisa e eficiente dos equipamentos.

## 📋 Requisitos Pré-instalação

Antes de iniciar o processo de instalação, certifique-se de ter os seguintes itens:

### 🎒 Materiais Necessários
- 🔌 Cabo USB para Micro USB (recomendado ter um de backup)
- 💻 Notebook ou PC
- 📎 Clip de reset (pode ser um clipe de papel)
- 🔋 Fonte de alimentação 12V com chicote original
- 🌐 Ferramenta de acesso remoto instalada (preferencialmente TeamViewer)

### ⚙️ Configurações Prévias
- 📝 ULID do cliente (para registrar devices fora da conta da Gol na AWS)
- 👤 Usuário AWS do cliente
- 🛠️ V3QATools versão 0.20.0 (versão compartilhada com Rastrac foi 0.14.0)

## 🔍 Validações Pré-instalação

Antes de prosseguir com a instalação, é necessário realizar as seguintes validações:

1. ✅ Confirmar se o equipamento está energizado
2. 💾 Verificar se o equipamento possui cartão SD
3. 📡 Confirmar configuração do APN
4. 📶 Verificar configuração da rede WiFi
5. 🔄 Confirmar versão do V3FW que será instalada

## 🚀 Processo de Instalação

Durante o processo de instalação, o cliente deve:

1. 🔌 Conectar o dispositivo ao computador via USB
2. 📱 Aguardar a detecção automática do dispositivo
3. ⚙️ Seguir as instruções da ferramenta V3QATools
4. ✅ Validar as configurações após a instalação
