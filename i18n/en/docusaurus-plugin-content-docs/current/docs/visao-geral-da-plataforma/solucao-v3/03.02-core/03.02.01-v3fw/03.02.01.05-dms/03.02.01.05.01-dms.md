# DMS (Driver Monitoring System)

DMS is an advanced system that monitors driver behavior based on visual data and vehicle speed to detect possible distractions and fatigue.

## How DMS Works

DMS uses a camera installed in the vehicle to observe driver behavior while driving.

The **V3FW** system constantly monitors driver movements, interpreting various facial expressions, such as eye or mouth openness.

## DMS Rules

DMS uses an intelligent rule system to process and interpret events captured by the camera. This system was designed to:

- **Prioritize critical events**: Some behaviors, such as drowsiness or cell phone use, are considered more critical and generate immediate alerts
- **Avoid repetitive alerts**: The system avoids generating multiple alerts for the same behavior within a short period
- **Consider context**: Rules are applied only when the vehicle is in motion (above 20 km/h)
- **Adapt to needs**: Detection thresholds can be adjusted according to the customer profile

### How Rules Work

1. **Data collection**: The system continuously captures information about:
   - Driver facial expressions
   - Head movements
   - Gaze direction
   - Specific activities (such as eating, drinking, using a cell phone)

2. **Intelligent processing**: Rules evaluate:
   - Activity duration
   - Behavior frequency
   - Situation context
   - Recent event history

3. **Alert generation**: The system decides when to generate an alert based on:
   - Event priority
   - Time since the last similar alert
   - Behavior severity
   - Custom settings

### Customization

The system allows adjusting various parameters to meet specific needs:
- Minimum time between alerts
- Detection thresholds for each behavior
- Event priority
- Specific operating conditions

This approach ensures that alerts are relevant and useful, avoiding both missing notifications and excessive unnecessary alerts.

### Operating Conditions

We can compose rules according to customizable parameters per device, for example:

- The vehicle is considered in motion if speed exceeds **20 km/h** (`MOVING_MIN_SPEED`).
- If the vehicle is not in motion, no distraction or fatigue events will be recorded.

## Detected Behaviors

DMS is capable of identifying various risky behaviors:

| **Behavior** | **Activation Condition** | **Threshold** |
|-------------------|----------------------------|---------------|
| Distraction by pose (`general`) | Driver in motion + Distraction time > X seconds | 5s |
| Distraction by head tilt (`pitch`) | Driver in motion + Distraction time > X seconds | 5s |
| Distraction by head rotation (`yaw`) | Driver in motion + Rotation time > X seconds | 5s |
| Distraction by gaze (`gaze distraction`) | Driver in motion + Gaze detected + Distraction time > X seconds | 5s |
| Gaze fixation (`gaze fixation`) | Driver in motion + Gaze detected + Fixation time > X seconds | 5s |
| Drowsiness (`drowsiness`) | Driver in motion + Fatigue index (PerClos) > X% | 20% |
| Eating | Driver in motion + Mouth detected + Eating time > X seconds | 5s |
| Drinking | Driver in motion + Mouth detected + Drinking time > X seconds | 5s |
| Using phone | Driver in motion + Phone holding time > X seconds | 5s |
| Smoking | Driver in motion + Mouth detected + Smoking time > X seconds | 5s |
| Yawning (`yawning`) | Driver in motion + Mouth detected + Yawning time > X seconds | 5s |

## Main Detection Categories

### 1. Inattention
The system detects when the driver is not looking at the road for too long, whether by turning their head or diverting their gaze.

### 2. Fatigue or Drowsiness
The system identifies signs of fatigue by observing prolonged eye closure or microsleeps (when the eye closes for a few seconds without the driver noticing).

### 3. Risky Activities While Driving
DMS also detects specific behaviors such as eating, drinking, talking on the phone, smoking, and yawning, which can compromise driver attention.

### 4. Camera Issues
The system alerts when the camera is covered or when the driver's face leaves the frame for a prolonged period.

## Main Benefits

- **Accident Prevention**: Alerts the driver about risky behaviors before they result in accidents
- **Continuous Learning**: Continuously improves performance by learning from driver patterns
- **Discrete Operation**: Runs in the background without interfering with the driving experience
- **Adaptability**: Works with different drivers and in different types of vehicles
