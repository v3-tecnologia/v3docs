# Introduction

**V3FW** is the embedded software on V3 devices, responsible for collecting, processing, and sending data captured by sensors to the cloud.

**V3FW** was designed to operate under different conditions, with a focus on efficiency and reliability. Its modular architecture allows adaptability to various types of hardware while maintaining consistent functionality and data processing quality.

## What You Will Find in This Section

This section presents the main features and components of **V3FW**, detailing how it collects and processes sensor data. The main topics covered are:

- [Telemetry](./03.02.01.02-telemetria.md): Sensor data collection and processing
- [MDVR](./03.02.01.03-mdvr.md): Media recording and retrieval system
- [Driver Behavior](./03.02.01.04-comportamento-condutor.md): Driving pattern analysis
- [DMS](./03.02.01.05-dms/03.02.01.05.01-dms.md): Driver facial monitoring system
- [Computer Vision](./03.02.01.06-visao-computacional.md): Image processing and analysis
- [Portability](./03.02.01.07-portabilidade.md): Adaptability to different hardware
