# Telemetry

Telemetry in **V3FW** is responsible for monitoring device sensors, generating a series of information transmitted as events to the cloud.

## How It Works

The system constantly monitors the sensors on the device where it is installed to generate telemetry events. These events enable various vehicle monitoring features such as:

- Real-time tracking
- Trip history
- Speed monitoring
- Acceleration analysis
- Risk behavior detection

## Main Data Fields

Telemetry events contain structured fields with specific information:

- **timestamps**: Temporal information about when the event occurred
- **gps**: Location and movement data
- **vehicle**: Vehicle state and battery information
- **connection**: Network connection information
- **media**: Details about associated media files
- **metadata**: Additional information about the firmware and device
