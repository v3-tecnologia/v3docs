# V3APP

**V3APP** is the mobile solution of the **V3** platform, offering access to information on iOS and Android devices. The application provides all the features of the web platform, adapted for an optimized mobile experience.

## Available Features

- **Search Bar (Top)** — Quick search for vehicles, drivers, and groups.
- **Navigation Menus** — Access to main features.
- **User Management** — Profile, logout, and personal settings.
- **Dynamic Filters** — Apply filters by vehicle, group, driver, date, and more.
- **View Modes**
  - **Map**
  - **List**
  - **Hybrid (Map + List)**
- **Heat Map** — Visualization of activity concentration.
- **Geofences** — Create and manage geofences on the map.
- **Map Layers** — Enable additional layers to enrich visualization.

## Administration

### Vehicles
- View data:
  - License plate
  - Chassis
  - Nickname
  - Associated rules
- View real-time position.

### Groups
- Create and edit vehicle groups.

### Users
- Create users.
- Set profile:
  - **Administrator**
  - **Standard**

### Drivers
- Register drivers.
- Link drivers to vehicles.
- Add photo (for indexing and facial identification).

### Notices
- Create and send notices to the entire fleet.
- View history of sent notices.
- Filter sent notices.
- **Note:** An email notice template is available.

### Rules
- Create operational rules.
- Associate rules with vehicles (individually or in groups).
- View summary of applied rules.

### Wi-Fi Networks
- Register and manage Wi-Fi networks.
- **Important:** Compatible only with **2.4 GHz** networks.

## Individual Notices

- Create personal notices.
- Manage and filter sent notices.

## Reports

### Trips
- Views:
  - **Map**
  - **Card**
  - **Driver**
  - **Trip Summary**
  - **Hybrid**
  - **List**
  - **Media by event**
- Features:
  - View vehicle details.
  - View clickable photos and videos.
  - Facial identification.
  - Associate new identification.
  - Replay trip (route replay).
  - Manage report columns.
  - Set number of items per page.
  - Export data.
  - Request media from device.

### Fleet Activity
- Detailed listing of vehicle activities.

### Violations
- View violations on the map.
- Track critical events.

## Geofences and Points of Interest

- Create, edit, and monitor geofences.
- Register and manage points of interest on the map.

## Fleet

- Centralized management of:
  - **Vehicles**
  - **Groups**
  - **Rules per Vehicle**
