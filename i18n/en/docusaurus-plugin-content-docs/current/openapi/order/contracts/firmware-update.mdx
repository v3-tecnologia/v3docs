The `FIRMWARE_UPDATE` order requests a firmware update for the device.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `version` | string | No | Requested firmware version. |
| `is_debug` | boolean | No | Indicates whether the firmware version is a debug build. Defaults to `false`. |

```json
{
  "orders": [
    {
      "type": "FIRMWARE_UPDATE",
      "correlation_id": "CMD_FIRMWARE_UPDATE_001",
      "parameters": [
        {
          "version": "2.4.0",
          "is_debug": false
        }
      ]
    }
  ]
}
```
