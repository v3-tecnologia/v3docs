Welcome to V3

Welcome to the official V3 documentation! This space has been carefully designed to guide you through a complete journey across our video telematics ecosystem, providing all the information you need to implement and get the most out of our platform.

About V3​

V3 is a Brazilian technology company specializing in computer vision for vehicle mobility. Our name stands for Vehicle, Video & Vision — a complete ecosystem spanning from hardware and embedded systems to predictive cloud analytics, with proprietary AI developed for the Brazilian market.

What you'll find in this documentation​

This documentation is organized by content type, so each user profile can quickly find what they need:

  1. Product and platform context

    • Understand V3's vision, solution principles, and use cases
    • Gain clarity on how components connect within the ecosystem

  2. Deployment and operational configuration

    • Learn how to prepare environments, devices, and credentials
    • Consult practical guides for installation and initial configuration

  3. API integration and operations

    • Access content on authentication, permissions, and operational management
    • Understand order, event, vision, and notification workflows

  4. Development kits

    • Consult language-specific references to accelerate implementation
    • Apply integration best practices with the platform

  5. Technical API and notification reference

    • Explore operations, contracts, and integration examples
    • Use the detailed reference for implementation and troubleshooting

How to use this documentation day to day​

  • If you're just getting started, focus first on platform context and configuration.
  • If you're already integrating, go straight to APIs, development kits, and technical reference.
  • If you're in operations, use the management, events, and notifications content as your daily reference.
